The short post is the last artifact. The more interesting system is the chain that connects a source to a claim, a draft to a genuine visual, and a public post to an accountable author.

Two repositories show an editorial progression

The first repository packages a community-maintained Hermes skill for researching, drafting, quality-checking, and publishing LinkedIn posts through a user-authorized Composio connection. Its README is explicit that the project is not affiliated with LinkedIn, Microsoft, Composio, or Nous Research.[9]

The expanded `hermes-linkedin-posts` repository extends the workflow to sourced posts with benchmark visuals, publishing, one-shot scheduling, and iteration from analytics snapshots. Together, the two repositories tell a coherent story: one packages a publishing skill; the other makes the editorial loop and its media checks more explicit.[12][13]

Research comes before the opening line

The workflow starts with primary sources and asks what they actually establish. The skill tells the writer to separate confirmed facts, company claims, estimates, and interpretation; it also says not to invent figures, quotes, results, or benchmark comparisons.[10][13]

That order changes the writing task. The opening still needs to earn attention, but the body has to carry the claim. If a source supports only a narrow comparison, the post should not quietly turn it into a universal ranking. If a metric is shown, the skill asks for its version, comparison, effort setting, cost basis, and caveats.[13]

A visual is evidence, not a shortcut

For benchmark and product posts, the expanded skill prefers genuine visuals from the source chart or table over an invented graphic. It calls out details that are easy to crop away by accident: the chart title, legend, axes, effort labels, and footnotes. A decorative takeaway can be added separately, but the underlying data must remain attributed and intact.[13]

That makes the visual step a fact-checking step. A chart with no visible axis or missing comparison label can be more persuasive than the evidence deserves. The skill explicitly says not to use generated imagery to invent benchmark data; its recommendation is to inspect the source and the final attachment before publishing.[13]

Publishing is a boundary, not an autocomplete

A draft or a link is not permission to publish. The first repository says that public posting or scheduling requires a clear request for the exact action and content. The expanded skill also requires an authorized LinkedIn connection and a checked author identity before a live write.[9][10][13]

After publishing, the workflow does not stop at an API success message. The instructions call for reading back the exact post, checking its visibility and media, and verifying any first comment against the intended post. That is how the workflow distinguishes “draft prepared,” “post created,” and “post actually visible.”[10][13]

Use analytics to choose a test, not declare a law

The expanded skill separates reach, engagement, watch time, profile activity, and follows. It asks writers to preserve the date window and denominator, show the numerator for rates, and treat low-volume results as directional. Its own documentation warns that the managed publishing connection may not provide read or analytics access.[13]

That is a better feedback loop than “the post got impressions, therefore this format always wins.” One observation can suggest a question for the next post; it cannot settle it. The point of analytics here is to build a small, bounded experiment while keeping the underlying sample and access limits visible.[11][13]

The durable idea is traceability

The workflow is useful even if the reader never installs either skill. Keep the source close to the claim. Keep the visual tied to the source. Keep the human decision between a finished draft and a public post. Then read the result back before calling the task complete.[10][13]

That is a more defensible publishing system than optimizing for output volume. The skills do not promise reach, universal analytics access, or automatic editorial judgement. They document a repeatable chain in which the author stays identifiable and the evidence stays checkable.
