Who is Amit?

Amit Elgabsi is an AI builder and open-source maker. This newsroom is a home for the projects he chooses to explain in depth: desktop assistants, agent plugins, research tools, and the workflows around them.

Each story links to the public repository it describes. The repository is the source of truth for installation instructions, current compatibility, licensing, and project status.

What does “+ Hermes” mean?

Hermes Agent is an AI agent built by Nous Research. Amit works with Hermes as an AI collaborator for research, implementation, testing, and documentation. Hermes is software, not a human co-author.

Amit is the publisher and retains responsibility for editorial standards and public release decisions. The existing project features were human-authored with AI assistance. If a future news report is generated by the scheduled desk, its byline will identify Hermes Agent’s role and explicitly state whether Amit reviewed it before publication.
